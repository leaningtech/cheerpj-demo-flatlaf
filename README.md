# CheerpJ Demo: FlatLaf Library Mode

This demo combines the FlatLaf's basic demo and theme editor JARs using CheerpJ's library mode. A preloaded theme is provided for you to explore, and you can create your own using the theme editor. This runs the original FlatLaf JARs directly in the browser using CheerpJ.

## Run Locally

```bash
git clone https://github.com/leaningtech/cheerpj-demo-flatlaf.git
cd cheerpj-demo-flatlaf
npx http-server
```
